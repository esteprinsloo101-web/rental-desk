# Rental Desk

**Rental Desk** is a polished, mobile-first static web demo of a South African **small landlord case manager**.

Sample portfolio: **Botha Rentals · Bloemfontein**. Demo / sample ZAR data only. **Not** legal advice.

Shared DNA with [Life Desk](https://esteprinsloo101-web.github.io/life-desk/) and [Farm Desk](https://esteprinsloo101-web.github.io/farm-desk/): the app **reminds, chases, prepares, closes**; human **Approves** deductions / Tribunal-oriented packs.

## Live URL

**https://esteprinsloo101-web.github.io/rental-desk/**

## Modules

| Module | Role |
|--------|------|
| **Today** | Due processes · reminders · occupancy / arrears KPIs |
| **Units** | Properties / units portfolio |
| **Cases** | Rent · exit/handover · snag · deposit cases |
| **Money** | Rent ledger · deposits held |
| **Tenants / leases** | Active leases · ending soon |
| **Snags / repairs** | Open tickets · contractor chase |
| **Docs** | Leases · evidence packs |
| **Settings** | Module toggles · processes · reset |

## Process types

- **Rent due** — review → chase (account links) → confirm received
- **Inspection walkthrough** — prep → **photo slots as checklist** → notes → close
- **Deposit close** — calc → Approve deductions → refund
- **Snag close** — review → chase contractor → verify closed
